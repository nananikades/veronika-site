# Veronika Kim — сайт-портфолио

Статический сайт на трёх языках (RU / KZ / EN).

- `build.py` — генератор: тексты, структура, страницы. Запуск: `python3 build.py` (нужен Pillow).
- `site/` — готовый сайт, его и публикует Vercel (см. `vercel.json`, сборка не нужна).
- `site/photos/<раздел>/` — фотографии по разделам. Файлы `stock-*.jpg` — временные фото из интернета.
- `covers-bw/` — прежние чёрно-белые обложки.

Локальный просмотр: `python3 -m http.server 4173 --directory site`
